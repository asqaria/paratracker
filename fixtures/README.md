# Эталонные фикстуры треков: IGC, GPX, KML, KMZ

Сгенерированы `tools/make-fixtures.mjs`. **Руками не править** — перегенерируй скриптом.

Каждый файл покрывает один граничный случай из ТЗ, задачи 0.8 и 1.2.
Точные ожидаемые значения — в `expected.json`: координаты посчитаны обратным
декодированием того, что реально записано в файл, поэтому тест может сверять до знака.

> Этот набор НЕ заменяет реальные треки с приборов. Те нужны, чтобы ловить
> диалекты конкретных моделей — их собирай отдельно и клади рядом.

| Файл | Что внутри | Что проверяет |
|---|---|---|
| `baseline.igc` | Эталонный нормальный трек. Всё как надо: 1 Гц, баро и GNSS, старый HFDTE, все фиксы A. | Базовый разбор: количество точек, координаты, высоты, дата. |
| `no-baro.igc` | Прибор не пишет барометрическую высоту — все поля 00000. | altitudeSource должен стать "gnss", в warnings — предупреждение. Вариометр считается по GNSS. |
| `alg-geo-phone.igc` | Телефон (XCTrack): HFALG:GEO, баро нет — высота над геоидом, как в реальных треках пилотов. | GNSS-высота переводится в эллипсоид: h = H + N (EGM96). Трек не висит над рельефом на высоту геоида. |
| `alg-ell.igc` | Логгер объявляет эллипсоид: HFALGALTGPS:ELL (как требует IGC FR Specification). | Высота остаётся как есть — пересчёт только для геоида. |
| `midnight.igc` | Полёт через полночь UTC: старт 23:50, финиш после 00:10 следующих суток. | Время следующей B-записи МЕНЬШЕ предыдущей → +1 сутки. Без этого вся вторая половина трека уедет на день назад. |
| `gaps.igc` | Два разрыва связи: 90 секунд и 12 минут. | Разрыв 90 с НЕ влезает в Uint16 миллисекунд (потолок 65.5 с) — проверка таблицы разрывов из ТЗ §5.4. Оба помечаются флагом gap, интерполяция через них запрещена. |
| `south-west.igc` | Аргентинские Анды: отрицательная широта И отрицательная долгота. | Знаки S и W. Классическая ошибка — потерять знак и отзеркалить трек в северное полушарие. |
| `date-modern.igc` | Современный формат даты HFDTEDATE:DDMMYY,NN (с 2016 года). | Парсер обязан понимать ОБА формата. На этом файле старая реализация не найдёт дату и уйдёт в fallback по имени файла. |
| `lad-lod.igc` | Расширения LAD и LOD — дополнительные знаки минут широты и долготы. | Без их учёта точность координат ограничена 0.001′ ≈ 1.85 м, и радиус виража в детекции кругов заметно шумит. Координаты в эталоне посчитаны С учётом расширений. |
| `sparse-10s.igc` | Шаг фиксов 10 секунд — типично для GPX с телефона и часов Garmin. | Медианный шаг > 4 с → analysis_level = "basic". Детекцию термиков и ветра НЕ запускать: интерполяция срежет виражи хордами и накопление курса не наберёт 360°. |
| `v-fixes.igc` | Каждый десятый фикс — 2D (флаг V вместо A). | Точки с V помечаются и исключаются из расчёта вертикальной скорости, но остаются в треке. |
| `negative-alt.igc` | Высоты ниже уровня моря — формат -NNNN. Мёртвое море. | Отрицательная высота не должна ломать парсер числа и не должна превращаться в 0. |
| `extensions-full.igc` | Полный набор расширений B-записи: FXA, SIU, GSP, ENL. | I-запись разбирается по позициям байтов, значения читаются по своим смещениям. FXA и SIU потом используются для фильтрации шума. |
| `broken-lines.igc` | Битые строки посреди валидного трека: обрезанная B-запись, мусор, неизвестный тип записи, пустая строка. | ГЛАВНЫЙ тест устойчивости. Парсер обязан пропустить их, записать в warnings и продолжить — не бросить исключение. Количество валидных точек должно остаться прежним. |
| `baseline.gpx` | Нормальный GPX 1.1 как у Garmin: trkpt с ele и time, расширения TrackPointExtension, метаданные с автором по-русски. | Базовый разбор GPX: точки, время ISO 8601, высота из ele. Баро нет → altitudeSource "gnss" и предупреждение. UTF-8 и сущности XML в метаданных. |
| `no-ele.gpx` | Телефон не записал высоту: ни у одной точки нет <ele>. | Парсер не падает: altGnss = null у всех точек и предупреждение no_gnss_altitude. |
| `time-offset.gpx` | Время с часовым поясом (+05:00) и долями секунды (.500) — так пишут многие телефонные трекеры. | Время приводится к UTC; доли секунды не теряются. |
| `segments.gpx` | Два <trkseg> с разрывом 90 секунд между ними. | Сегменты склеиваются в один трек по времени; разрыв остаётся разрывом. |
| `fix-2d.gpx` | Каждая десятая точка — <fix>2d</fix>; у всех точек <sat>7</sat>. | 2D-фиксы помечаются valid = false, число спутников читается в siu. |
| `broken.gpx` | Битые точки посреди трека (широта 95°, нет времени, время не ISO), текстовый мусор между точками и файл, оборванный посреди последней точки. | Парсер не бросает: битые точки пропущены с предупреждением, мусор проигнорирован, обрыв — предупреждение truncated_document, всё до обрыва сохранено. |
| `gx-track.kml` | Google Earth KML с <gx:Track>: списки <when> и <gx:coord>, altitudeMode absolute. | Время из <when> сопоставляется с <gx:coord> по порядку; координаты в порядке «долгота широта высота». |
| `multitrack.kml` | <gx:MultiTrack> из двух сегментов с разрывом 90 с, записанных в документ в обратном порядке, и рядом метка с LineString того же пути без времени. | Сегменты склеиваются по времени, а не по порядку в документе. LineString игнорируется, раз есть gx:Track со временем. |
| `linestring-timespan.kml` | Старый прибор: только <LineString> без времени у точек, у метки <TimeSpan> (после геометрии). | Время распределяется равномерно по TimeSpan, предупреждение timestamps_interpolated. Порядок элементов внутри метки не важен. |
| `gx-track.kmz` | KMZ — zip-архив (deflate) с doc.kml внутри; doc.kml лежит не первым файлом. | Архив распаковывается, выбирается doc.kml, дальше — как gx-track.kml. |

## Реальные треки

Не генерируются — лежат рядом с генерированными и при перегенерации не трогаются.
Кладутся только с согласия владельца и обезличенными: `tools/anonymize-igc.mjs`
(без пилота, крыла, серийного номера, места, комментариев и подписи).
Разметка — в `<файл>.labels.json` рядом.

| Файл | Что внутри | Что проверяет |
|---|---|---|
| `real-wind-thermals.igc` | 4 ч 54 мин, XCTrack, 1 Гц; термик в ветре ~35 км/ч; разметка владельца в `real-wind-thermals.labels.json` | Детекция термиков против ручной разметки (ТЗ §6.3, DoD фазы 2): подтверждённые находятся, пропущенный в ветре — одним термиком, пара кругов в слабом пузыре — не термик |
