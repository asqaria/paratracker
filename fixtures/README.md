# Эталонные IGC-фикстуры

Сгенерированы `tools/make-fixtures.mjs`. **Руками не править** — перегенерируй скриптом.

Каждый файл покрывает один граничный случай из ТЗ, задача 0.8.
Точные ожидаемые значения — в `expected.json`: координаты посчитаны обратным
декодированием того, что реально записано в файл, поэтому тест может сверять до знака.

> Этот набор НЕ заменяет реальные треки с приборов. Те нужны, чтобы ловить
> диалекты конкретных моделей — их собирай отдельно и клади рядом.

| Файл | Что внутри | Что проверяет |
|---|---|---|
| `baseline.igc` | Эталонный нормальный трек. Всё как надо: 1 Гц, баро и GNSS, старый HFDTE, все фиксы A. | Базовый разбор: количество точек, координаты, высоты, дата. |
| `no-baro.igc` | Прибор не пишет барометрическую высоту — все поля 00000. | altitudeSource должен стать "gnss", в warnings — предупреждение. Вариометр считается по GNSS. |
| `midnight.igc` | Полёт через полночь UTC: старт 23:50, финиш после 00:10 следующих суток. | Время следующей B-записи МЕНЬШЕ предыдущей → +1 сутки. Без этого вся вторая половина трека уедет на день назад. |
| `gaps.igc` | Два разрыва связи: 90 секунд и 12 минут. | Разрыв 90 с НЕ влезает в Uint16 миллисекунд (потолок 65.5 с) — проверка таблицы разрывов из ТЗ §5.4. Оба помечаются флагом gap, интерполяция через них запрещена. |
| `south-west.igc` | Аргентинские Анды: отрицательная широта И отрицательная долгота. | Знаки S и W. Классическая ошибка — потерять знак и отзеркалить трек в северное полушарие. |
| `date-modern.igc` | Современный формат даты HFDTEDATE:DDMMYY,NN (с 2016 года). | Парсер обязан понимать ОБА формата. На этом файле старая реализация не найдёт дату и уйдёт в fallback по имени файла. |
| `lad-lod.igc` | Расширения LAD и LOD — дополнительные знаки минут широты и долготы. | Без их учёта точность координат ограничена 0.001′ ≈ 1.85 м, и радиус виража в детекции кругов заметно шумит. Координаты в эталоне посчитаны С учётом расширений. |
| `sparse-10s.igc` | Шаг фиксов 10 секунд — типично для GPX с телефона и часов Garmin. | Медианный шаг > 4 с → analysis_level = "basic". Детекцию термиков и ветра НЕ запускать: интерполяция срежет виражи хордами и накопление курса не наберёт 360°. |
| `v-fixes.igc` | Каждый десятый фикс — 2D (флаг V вместо A). | Точки с V помечаются и исключаются из расчёта вертикальной скорости, но остаются в треке. |
| `negative-alt.igc` | Высоты ниже уровня моря — формат -NNNN. Мёртвое море. | Отрицательная высота не должна ломать парсер числа и не должна превращаться в 0. |
| `extensions-full.igc` | Полный набор расширений B-записи: FXA, SIU, GSP, ENL. | I-запись разбирается по позициям байтов, значения читаются по своим смещениям. FXA и SIU потом используются для фильтрации шума. |
| `broken-lines.igc` | Битые строки посреди валидного трека: обрезанная B-запись, мусор, неизвестный тип записи, пустая строка. | ГЛАВНЫЙ тест устойчивости. Парсер обязан пропустить их, записать в warnings и продолжить — не бросить исключение. Количество валидных точек должно остаться прежним. |
